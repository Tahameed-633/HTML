# 🌐 HTML Practice & Learning

Welcome to my **HTML Practice Repository**! 👋

This repository contains my HTML practice files and examples as I learn the fundamentals of **HTML (HyperText Markup Language)** and web development.

## 📚 Topics Covered

Throughout this repository, I am practicing:

* HTML document structure
* Headings (`h1` – `h6`)
* Paragraphs (`p`)
* Line breaks (`br`)
* Horizontal lines (`hr`)
* Links (`a`)
* Images (`img`)
* Attributes
* Alternative text (`alt`)
* Page titles (`title`)
* Preformatted text (`pre`)
* Inline CSS using the `style` attribute
* Text alignment
* Basic HTML elements and tags

## 💻 Example

A basic HTML document:

```html
<!DOCTYPE html>
<html>
    <head>
        <title>My Portfolio</title>
    </head>

    <body>
        <h1>About Me</h1>
        <p>This is my first HTML webpage.</p>
    </body>
</html>
```
